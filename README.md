# modphi
Python code for the manipulation of the cumulants of statistics of random objects.

# Installation

```bash
git clone https://github.com/darkxan771/modphi.git
```

In the jupyter/ folder, one can launch `jupyter lab`, 
then create a Python notebook and execute in the first cell: 
```python
import sys
sys.path.insert(0, "../src/")
from modcalculus import *
```
